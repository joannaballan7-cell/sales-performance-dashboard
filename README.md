# Sales Performance Dashboard

## Project Overview

This project is an interactive Power BI dashboard designed to analyze sales performance and provide business insights. The dashboard helps identify sales trends, regional performance, and product performance.

## Tools Used

* Power BI
* Data Visualization
* Dashboard Design
* Business Intelligence

## Dashboard Features

The dashboard includes:

* Total Sales KPI
* Sales by Region analysis
* Sales by Product analysis
* Sales trends over time
* Interactive filtering

## Business Questions Answered

* What are the total sales?
* Which regions generate the most sales?
* Which products perform best?
* How do sales change over time?

## Files Included

* `Sales_Performance_Dashboard.pbix` — Power BI dashboard file
* `dashboard_screenshot.jpg` — Dashboard preview image

## Project Goal

The goal of this project was to practice building business intelligence dashboards and transforming sales data into clear, actionable insights.
